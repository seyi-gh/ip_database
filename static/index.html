What you get

Every IP lookup returns a rich set of data from multiple sources.

location_on

Geolocation

Country, region, city, postal code, coordinates, and timezone from two independent databases.

corporate_fare

ASN & Organization

Autonomous System Number, organization name, and domain for any IP range.

public

Continent data

Full continent name and code alongside country information.

label

Company whitelist

Identifies IPs belonging to known companies like Microsoft, Webex, or HPE.

bolt

Fast lookups

PostgreSQL with indexed integer ranges — no full scans, sub-millisecond queries.

lock

Secure by default

Rate limiting, security headers, and private IP blocking on every request.
